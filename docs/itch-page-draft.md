## Title
ADHD Planer

## Short tagline (EN)
Visual canvas + timeline for worldbuilding and ADHD-friendly project planning.

## Price
Pay what you want (~$5 / €5 suggested)

## Description (EN)

ADHD Planer is a local desktop tool for people who think in **images and connection lines**, not outlines.

- Visual mind-map canvas (shapes, sticky notes, images, links)
- Timeline under the canvas for chronology
- Notes + notebook pages
- Master document panel (write / import PDF or ODT)
- No account, no cloud — your files stay on your machine

I built it for my own sci-fi worldbuilding (Astrum Invictum). Simulation mode exists but is **experimental** in 0.1.

**Windows portable** — unpack / run, no Python install needed.

## Popis (CZ)

ADHD Planer je lokální nástroj pro lidi, co myslí **obrazy a spoji**, ne osnovami.

- Canvas (uzly, sticky, obrázky, vazby)
- Timeline dole
- Poznámky a notebook
- Hlavní dokument (text / import PDF·ODT)
- Bez účtu a cloudu

Simulační mód je v 0.1 **experimental**.
